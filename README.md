# Rodaya

Landing page académica para presentar una plataforma de alquiler de equipos audiovisuales. Usa HTML, CSS y JavaScript. El catálogo usa datos de demostración.

## Ejecutar

Abre `index.html` en un navegador. También puedes servir la carpeta con cualquier servidor HTTP estático. Las fuentes Poppins e Inter se solicitan a Google Fonts y tienen alternativas locales.

## Estructura

- `index.html` contiene la navegación y las secciones de la landing.
- `styles.css` contiene la guía visual y las reglas adaptables.
- `main.js` controla el menú móvil y los filtros del catálogo.
- `camera.jpg` es la fotografía de portada.

## Publicación

Publica el contenido de la carpeta en la raíz de `main`. En el repositorio abre **Settings → Pages**, selecciona **Deploy from a branch** y elige `main` y `/(root)`. Verifica la página desde la dirección que aparece en GitHub Pages.
